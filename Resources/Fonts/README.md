RobotoCondensed-Italic.ttf is a static, regular-weight italic instance of
[Roboto Condensed](https://github.com/google/fonts/tree/main/ofl/robotocondensed).
Its SIL Open Font License and copyright notice are in RobotoCondensed-OFL.txt.

The source is RobotoCondensed-Italic[wght].ttf from that directory. This bundled
instance was exported with fontTools.varLib.instancer at wght=400, retaining the
font's character set and license metadata. It is the fallback for non-default
chat languages when the selected font has no registered italic variant.
